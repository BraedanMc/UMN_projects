# UMN Projects Portfolio

**Author**: Braedan McCluskey (bmcc@umn.edu)  
**Last Updated**: 2026-09-28

This repository is a record (in the works!) of the bioinformatics projects I've worked on at the University of Minnesota. Each project should include links to the corresponding GitHub repositories (private but accessible with appropriate permissions). All projects created prior to October 2025 were migrated from github.umn.edu, so their activity and commit history are not reflected in this GitHub account.

## Molecular Diagnostics Lab Projects

- **[CLIA-compliant whole genome sequencing pipeline](https://github.com/umn-msi-mdl/clia_wgs)**  
  *CLIA-compliant whole genome sequencing pipeline.*  

- **[Containerized nf-core/sarek WGS variant calling](https://github.com/umn-msi-mdl/nf_clia_wgs)**  
  *Containerized nf-core/sarek deployment for whole-genome variant calling, with local, HPC, and AWS layouts.*  

- **[Minimal Nextflow setup for CLIA WGS development](https://github.com/umn-msi-mdl/nf_clia_wgs_simple)**  
  *Minimal local Nextflow setup for developing CLIA whole-genome workflows.*  

- **[Archived Nextflow refactor of clinical WGS](https://github.com/umn-msi-mdl/clia_wgs_hst)**  
  *Nextflow and container refactor of the clinical whole-genome pipeline, later archived.*  

- **[CLIA-compliant hybrid capture sequencing pipeline](https://github.com/umn-msi-mdl/clia_oncology)**  
  *Clinical capture-sequencing pipeline for a cancer gene panel.*  

- **[CLIA germline panel pipeline](https://github.com/umn-msi-mdl/clia_germline)**  
  *Clinical germline panel SNV and indel pipeline.*  

- **[CLIA pharmacogenomics pipeline](https://github.com/umn-msi-mdl/clia_pgx)**  
  *Clinical pharmacogenomics pipeline that calls star alleles.*  

- **[MSIsensor2 capture-panel marker review](https://github.com/BraedanMc/msisensor2)**  
  *Site, coverage, and bait-region comparisons for microsatellite-instability markers.*  

- **[CLIA pipeline quality-control report](https://github.com/umn-msi-mdl/clia_qc)**  
  *Collects quality-control metrics from CLIA pipelines into a report.*  

- **[MitoHPC staging](https://github.com/umn-msi-mdl/temp_MitoHPC)**  
  *Staging area for troubleshooting mitochondrial calling before adding it to a CLIA pipeline.*  

- **[Clinical pipeline validation](https://github.com/umn-msi-mdl/validations)**  
  *Code and methods for clinical pipeline validation and concordance testing.*
